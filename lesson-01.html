About 10–15 minutes with the task · Read, attempt, then explain

The idea

Coordinates are addresses, not extra chess theory. Files run a–h from White’s left to right; ranks run 1–8 from White toward Black. Those names stay fixed when the board is rotated. Use the four central squares as anchors: d4, e4, d5, e5. Then locate a target relative to an anchor instead of recounting the whole board. A stable map makes a spoken line or written move much easier to retain.

Worked explanation

A knight on f3 is one file right and one rank below e4 from White’s view. On a board shown from Black’s side it is still on f3. The picture changed; the address did not.

Try it yourself

Point to a1, h8, e4, d5, and f3. Rotate the board and find them again. Work accurately before trying to beat a time.

Reveal the task answer and reasoning

The same five squares must be identified in both orientations. If rotation causes errors, name the file and rank separately before pointing.

The mistake to watch for

Learning squares only from White’s view makes Black positions unnecessarily difficult.

Close the lesson and test your recall

Do square names change when the board is flipped? No. Only their position on your screen changes.
